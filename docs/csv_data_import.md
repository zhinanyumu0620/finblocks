# CSV接入与独立真实案例

2026-10-06更新。采用“完整软件 + 小型真实案例 + 用户自有数据”的交付方式，不要求组员取得原始大行情包才能试用。官方材料未明确要求打包全部沪深300数据；这不等于已经满足全部参赛条件。作品仍须可复现核心功能、保留真实测试及来源依据，并按官方栏目提交材料。

## 直接演示

启动软件，点击顶部 **载入真实案例**，再依次点击 **检查股票池数据 → 运行真实回测**。案例是AAPL、IBM、MSFT的2012年历史日线，每股250条，共750条。它不代表沪深300、最新行情或实盘。

策略是MA5严格高于MA20时入选、否则空仓，三股共享现金、每日调仓、最多3只、单股上限1/3。成本10基点、信号滞后1条、每年252收益周期、无风险率0，均为可编辑演示假设，不是官方规则或市场收费标准。因子栏预填 `close / MA(close, 20) - 1`，需要用户另外确认实验协议再执行，不自动调用AI。

下载的策略文件也可从“导入策略”导入：`examples/sample_case.json`。示例CSV和策略的下载入口在“导入行情CSV”弹窗中。完整来源和许可见 `data/sample/manifest.json`、`data/sample/LICENSE_BOKEH.txt`。

## 导入自己的行情

点击 **导入行情CSV**，选择文件，填写数据集名称、真实来源/使用依据、复权口径及币种，并确认使用权限和成交量单位。先对整份CSV校验，通过后切换到新数据源。上传仅保存和校验，不调用AI。

| 含义 | 英文表头 | 支持的中文表头 | 要求 |
|---|---|---|---|
| 标的代码 | symbol / code | 股票代码 | 必填，1–24位字母、数字、点、横线、下划线；按原代码保留，不猜测市场 |
| 名称 | name | 股票名称 | 可选；未提供时显示代码；同一代码名称须一致 |
| 日期 | date | 交易日期 | 必填，真实的YYYY-MM-DD；一个代码同一天只允许一条 |
| 开盘价 | open | 开盘价 | 必填，有限正数 |
| 最高价 | high | 最高价 | 必填，须覆盖开盘、收盘、最低价 |
| 最低价 | low | 最低价 | 必填，须不高于开盘、收盘、最高价 |
| 收盘价 | close | 收盘价 | 必填，有限正数 |
| 成交量 | volume | 成交量 | 必填，有限正数，单位为股；原数据为“手”须先按真实口径转换 |
| 前收盘价 | previous_close | 前收盘价 | 可选；提供则严格校验与前一条收盘一致，异常阻断，不自动覆盖 |

第一行必须为表头，UTF-8（可带BOM）或GB18030编码。每份最多2MB、30000行、300个标的、40列，每个身份最多30份快照；这些是本项目的资源预算，不是比赛规则。

重复、缺失、NaN/Inf、非正价格/成交量、异常OHLC、日期错误、歧义表头都阻断整次导入。每个代码按日期升序排列，既不删记录，也不插值补价。未知列在审计中列为忽略，不会自动变成基本面因子。

未提供前收盘价时，由同一CSV上一条收盘派生；第一条沿用自身收盘仅作校验占位。它不是供应商官方前收盘参考价，也不能证明企业行动、复权或交易日连续性正确。用户须提供一致的OHLC口径、币种和成交量单位；软件不自动复权、转换币种或识别交易所。暂停交易的零成交量仍阻断，因为内核没有完整停牌撮合。

## 来源、快照与账号

用户CSV保存在运行服务的机器 `private/csv_datasets/`，不写入公开样例或覆盖原始ZIP。登录账号只能加载自己的快照；未登录的导入属于共同游客身份，敏感资料请先登录。账号、数据和密钥不会自动跨成员同步。共享包白名单不包含这个私有目录。

每次成功导入创建新的不可变数据源ID；记录原CSV的SHA-256、来源声明、币种、价格口径、字段映射与审计。回测报告保留这些信息。重启后可恢复同一账号的数据源；篡改CSV会阻断加载。导出的策略只包含数据源ID，其他电脑或账号必须先导入自己的文件并重新选择来源，软件不会静默回退到别的数据。

用户填写的来源/权利声明不等于平台独立核验授权。基本面PIT、历史成分池、完整撮合仍未实现。当前接入方式是手动CSV，没有新增行情供应商API连接器。
