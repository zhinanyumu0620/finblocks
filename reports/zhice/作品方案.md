# 智策工坊 作品方案

AI可视化量化研究平台
赛题2：AI+软件创新
版本日期：2026-10-06

## 作品简介

智策工坊面向金融知识较少的量化学习者，将自然语言需求转为可检查的策略积木，并用真实数据执行回测。支持AI策略与因子候选、技术指标、股票池共享资金回测、因子类型解释与文献参考、训练验证及冻结测试、风险提示和证据导出。软件提供小型真实历史案例，也允许用户导入自己的CSV；来源、口径、策略和执行假设可追溯。专业术语附解释与结果解读，不使用假行情，不承诺投资收益。

## 一、项目概述

### （一）项目背景与意义

面向金融初学者，策略描述、数据选择和风险判断的学习成本较高。本项目通过可见的策略结构、专业术语解释和真实结果复核，提供可以自行操作的研究流程。用户需求与教学效益尚需真实用户实验验证。

### （二）赛题方向定位

本作品选择算法创新赛赛题2“AI+软件创新”，以AI辅助策略构建、证据解释与因子探索形成完整研究软件。当前交付的软件形态与目标用户如下。

| 定位 | 当前交付 |
| --- | --- |
| 赛题 | 赛题2：AI+软件创新 |
| 用户 | 量化学习者、金融初学者及教学演示使用者 |
| 形态 | 本地Web软件，Python 3.10+，无运行依赖安装 |
| 数据交付 | 完整软件、小型真实案例、自有CSV接口 |

### （三）目标任务

选择数据源与日期，人工搭建或AI生成候选；检查字段、算子、依赖和预热；用户确认后执行单股或组合；查看基准、风险和逐日账目；保存策略与来源依据。修改配置立即使旧结果失效。

用户需求为产品定位假设，尚未开展用户计时实验、学习效果实验或市场试点；不宣称已验证用户规模或效率提升。

## 二、技术架构与技术选型

| 模块 | 职责 | 主要源码 |
| --- | --- | --- |
| 浏览器工作台 | 积木、来源选择、导览、账号和个人AI配置 | web/app.js、experience.js、ai-settings.js |
| 本机HTTP服务 | 请求约束、归属校验、回测与导出 | finblocks/web.py |

应用执行层仅用Python标准库；浏览器采用原生HTML/CSS/JavaScript，研究记录与账号存储使用SQLite。AI接口支持DeepSeek、OpenAI、通义千问、Kimi及自定义兼容服务，由用户填写实际可用模型ID。快捷预设不是每家模型均已真实调用通过的证明。

模型升级通过兼容接口替换；DSL白名单与数据能力门槛保持独立。没有把模型输出当作Python/JavaScript执行。离线案例可运行，真实AI功能需要合法Key与网络。

### 初学者体验

界面保留MA、夏普、IC等专业名词，问号展示定义、判断方向、经验参考、局限和当前真实结果。首次可选导览；用户名/密码测试账号不绑定手机号或邮箱。新手可用性仍需实际目标用户验证。

## 四、功能设计与AI实现

AI实际参与自然语言到DSL的候选生成、受约束因子候选与证据解释。模型负责提出结构，本地确定性内核计算信号、账目和收益。未配置Key或请求失败时明确报错，不返回预录模型响应冒充本次调用。

| AI与软件环节 | 实际实现与贡献 |
| --- | --- |
| AI策略生成 | 自然语言转为可编辑DSL积木；真实DeepSeek调用记录680 token |
| 候选意图审计 | 程序核对明确字段、窗口、条件和仓位；定位节点差异并预览补丁 |
| AI证据解释 | 引用指标、节点或账目证据ID组织说明；保存真实1332 token响应 |
| AI因子候选 | 提出价量表达式、研究假设和失效情景；保存真实447 token响应 |
| 计算与风险 | 技术指标、共享资金回测、分段验证；收益由内核计算 |
| 数据与交互 | CSV校验、数据指纹、账号快照、术语解释与操作引导 |

三个AI环节的实际模型均为deepseek-flash，历史策略、因子与解释JSON随复现证据提供；本轮没有新增模型调用。意图审计、因子分类和文献匹配由有限程序规则实现，不宣传为大模型完整语义证明或自动论文搜索。

文献参考为人工核验库，不是自动联网全文检索；结构分类不证明因子经济机制或原创性。AI只接收用户需求或明确确认的研究摘要，不自动上传全部行情。

有限意图审计主要核对明确双MA条件，不能保证复杂自然语言与DSL等价。已复现遗漏RSI未阻断、正确AND被根条件规则误阻断，需人工逐项核读并在正式提交前修复。结构编译校验与自然语言语义审计是不同层次。

## 五、数据与可复现交付

样例来自Bokeh官方bokeh_sampledata固定提交4195d5e5c3094ef578be168778c7e9501138f921，AAPL、IBM、MSFT各250条2012年日线，共750条。实际范围2012-01-03至2012-12-31，币种USD、成交量股。保留原OHLCV，不混用Adj Close；完整上游BSD-3-Clause许可随包保留。企业行动与复权未独立核验。

样例仅约42KB，750行字段全量通过校验。用户CSV要求symbol/date/open/high/low/close/volume，可选name与previous_close；支持实际中文字段及UTF-8/GB18030。重复日期、缺失值、异常OHLC或零成交量阻断整次导入，不补造数据。

每次导入保存新的来源ID、原CSV SHA与用户声明。登录账号仅可加载自己的快照，游客属于共同游客身份；私有目录不会进入共享包。未提供前收盘价时由上一条收盘派生并披露，不能替代复权/企业行动核验。

本地沪深300名单与原始大ZIP模式继续保留，源码包不分发原始完整行情。选择自有CSV时股票集合只来自该文件，不能标成沪深300。

单份2MB、30000行、300标的、40列，每身份30快照属于本项目预算，非比赛规则。

## 七、应用案例与结果

案例参数：三只股票共享初始资本1，MA5高于MA20入选，否则空仓；最多3只、单股上限1/3、每日调仓；成本10基点、滞后1条、年化252、无风险率0。全部为演示研究假设，不是官方或交易所参数。

| 项目 | 实际值 | 解释 |
| --- | --- | --- |
| 组合累计收益 | 1.50% | 扣除配置成本后的研究结果 |
| 同池等权基准 | 10.56% | 同样币种/样本/成本，不是沪深300指数 |
| 最大回撤 | -13.99% | 保留负号，表示相对此前峰值的下降 |
| 策略 / 基准夏普 | 0.201 / 0.668 | 年化252，年无风险率0的研究假设 |
| 真实记录 / 买卖明细 | 250 / 422 | 250个共同日历日期，422条买卖记录 |

## 八、应用价值与展望

公式close / MA(close,20) - 1；5条未来收益标签，按共同日历60%训练、20%验证、剩余测试。各段标签目标日不得跨段，训练/验证接口不提前展示测试指标，冻结时重新核对样本SHA。

训练与验证的秩相关为正，冻结测试段为负。方向变化是风险线索，不能单独证明过拟合；本软件没有计算PBO或DSR，不允许AI给出虚构概率。

当前可服务课堂演示、策略描述核读和个人研究复现。转化设想为教学软件与小团队研究工具，尚未取得付费、合作或用户增益证明，不估算未经调查的市场规模。

### 成果、边界和下一步

当前为日频、无杠杆、分数持仓研究。整手、完整T+1、涨跌停、真实滑点、分红再投资、财报PIT和实盘订单未实现。当前成分池回看历史存在选样/存活偏差。用户来源声明不等于平台核验数据授权。

优先修复复合意图审计，完成浏览器及真实新手任务验证；随后补充参数邻域、成本/换手因子检验及统计多重尝试方法。基本面因子须先核验PIT；历史成分与交易制度须有真实数据和实现后再开放。
