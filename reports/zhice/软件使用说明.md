# 智策工坊 软件使用说明

安装、真实案例、自有数据、AI配置与研究流程

## 安装与首个真实案例

完整解压源码与演示包，已有Python 3.10+即可。Windows双击start.cmd；macOS/Linux执行python3 start_finblocks.py。启动终端显示本机网址并尝试打开浏览器。127.0.0.1只能在运行机器访问，不能直接发给其他电脑使用。

页面点击“载入真实案例”，切换到三股共享资金组合，检查日期、成本、滞后和仓位。再点击“检查股票池数据”，全部通过后“运行真实回测”。结果应与本案例报告一致；不能把它当作沪深300回测。

| 项目 | 实际值 | 解释 |
| --- | --- | --- |
| 组合累计收益 | 1.50% | 扣除配置成本后的研究结果 |
| 同池等权基准 | 10.56% | 同样币种/样本/成本，不是沪深300指数 |
| 最大回撤 | -13.99% | 保留负号，表示相对此前峰值的下降 |
| 策略 / 基准夏普 | 0.201 / 0.668 | 年化252，年无风险率0的研究假设 |
| 真实记录 / 买卖明细 | 250 / 422 | 250个共同日历日期，422条买卖记录 |

查看真实净值、持仓、买卖及现金。修改任一配置使旧结果失效，必须重新检查并运行。关闭启动终端停止软件。

## 自有数据、账号和AI设置

点击“导入行情CSV”，选择文件，填写名称、实际来源/使用依据、币种与价格口径，并确认权限和股数单位。异常记录会阻断整份导入；上传不会自动调用AI。新数据源只显示该CSV标的，重启后同账号可恢复。

CSV首行须有symbol/date/open/high/low/close/volume。中文别名、编码、预算和前收盘派生详见代码包docs/csv_data_import.md；同一代码日期不得重复，OHLC须一致，量须为正。零量停牌行暂不能通过内核。

用户名/密码测试账号不需要手机号或邮箱。默认未登录属于共同游客身份；私有数据建议先登录。切换账号会清空研究状态，旧请求返回不会把原账号数据写入新账号。

注册/登录可选AI服务商，或点击“AI设置”。填写API根地址、模型ID和个人Key；保存不调用模型，“测试连接”可能计费。默认Key仅用于本次登录，Windows可选系统加密记住。自定义接口须支持兼容Chat Completions与JSON输出；聊天网页网址不是API根地址。

AI候选须核读具体积木和时点，再应用与回测。未配置Key、网络失败或DSL不合法会明确报错；人工案例离线运行，无需AI。

## 因子、解释、导出及常见失败

“载入真实案例”同时预填close / MA(close,20) - 1、三股横截面、5条预测跨度、60%训练/20%验证与每段样本门槛5。先确认协议，运行训练/验证；冻结后才查看最终测试。查看过测试后再改参数，后续结果属探索，不能认领独立检验。

类型解释来自字段与算子结构，关键词和论文参考来自核验库；不证明首次发现。风险表区分已执行、未执行和证据不足，因子IC不是策略收益。AI解释只发送用户确认的证据摘要。

“保存策略”导出含配置的工作台JSON，可由“导入策略”恢复。回测可导出JSON报告、CSV账目和PNG净值。CSV数据源ID按账号和机器隔离，跨机器分享策略后需重新导入自己的行情并选择新来源。

| 失败提示 | 处理方法 |
| --- | --- |
| 引用不存在的节点 | 核对id与input/left/right，禁止自动连接不存在的节点 |
| CSV日期重复/价格异常 | 回查真实源文件并重新导入，勿补零或补造价格 |
| 共同日历不完整 | 明确调整集合/区间，软件不静默删日期或删股 |
| 记录不足 | 扩大真实覆盖，保留预热和分区标签隔离 |
| 复合意图误判 | 人工核读所有条件；当前有限审计不保证复合语义 |
| 源快照变化 | 重新导入并重新验证，不复用旧冻结记录 |
