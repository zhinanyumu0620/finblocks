# 智策工坊：4分40秒逐步操作台本

这份台本可放在第二块屏幕上照着操作。主线为：真实AI生成策略 → 可视化积木 → 明确项审计与修复 → 三股共享资金回测 → 因子分类与论文参考 → AI解读训练/验证 → 冻结测试 → 导出。

时段是剪辑后的目标时间，不是对API响应速度的承诺。官方要求MP4、3–5分钟、300MB以内；4分40秒、1920×1080为本项目录制建议。录制完整操作，剪去无关等待后控制时长；不要加速到看不清关键动作。

## 一、录制前准备，不计入视频

1. 打开 `http://127.0.0.1:8765/`。只录浏览器窗口，关闭其他页面、聊天和通知，不录任务栏和桌面。录制前按F11进入全屏；若画布不完整，可用Ctrl+-适度缩小，务必保证文字可读。
2. 如果出现“是否开启新手引导？”，点击“暂不使用”。如正在引导，点击“退出引导”。录制主线不演示注册，使用游客或无身份测试账号；切换账号后要重新完成准备。
3. 顶部点击“AI设置”。保留已验证配置；若尚未配置，填写真实服务商的API根地址、可用模型ID和你自己的API Key，点击“保存配置”。如需“测试连接”，在录制前完成，它会产生真实请求并可能收费。保持“显示本次输入的密钥”不勾选。关闭设置。正式录制不拍密钥输入、账号页或费用账单。
4. 顶部点击“载入真实案例”。不要点右侧的“载入组合回测示例”，后者是另一套四股原始数据案例。
5. 在右侧“回测配置”核对下面的数值，原则上无需修改：

| 页面字段 | 固定案例应显示 |
|---|---|
| 回测模式 | 股票池组合回测 |
| 行情数据源 | 内置真实案例 · 美股历史日线 |
| 股票池 | 所选CSV标的 |
| 组合股票集合（代码以逗号分隔） | `AAPL, IBM, MSFT` |
| 最大持股数 | `3` |
| 单股目标仓位上限（%） | 一键载入的精确1/3，约33.333333%；不要重新输入33.33 |
| 调仓间隔（共同日历记录数） | `1` |
| 开始日期 / 结束日期 | `2012-01-03` / `2012-12-31` |
| 交易成本情景 | `10` 基点 |
| 信号执行滞后 | `1 条记录` |
| 年化周期数 / 年化无风险利率 | `252` / `0` |

6. 点击顶部导航“AI研究与审计”，在“意图描述”输入下文，并在右侧“明确项契约”预先填好。此时不用点击审计或修复：

```text
收盘价的5日均线持续高于20日均线时，目标仓位为100%；否则空仓。
```

| 明确项契约字段 | 填写 / 选择 |
|---|---|
| 行情字段 | 收盘价 |
| 根条件 | 持续高于 |
| 左侧MA窗口 / 右侧MA窗口 | `5` / `20` |
| 条件为真持仓（%） / 条件为假持仓（%） | `100` / `0` |

7. 点击“因子实验室”，确认一键案例已填入下面的协议。暂不运行，不提前冻结测试：

| 因子字段 | 输入值 |
|---|---|
| 因子表达式 | `close / MA(close, 20) - 1` |
| 评价模式 | 横截面IC / Rank IC（至少3标的） |
| 股票代码（逗号分隔） | `AAPL, IBM, MSFT` |
| 开始日期 / 结束日期 | `2012-01-03` / `2012-12-31` |
| 预测跨度（共同日历记录数） | `5` |
| 每区间最低有效样本 | `5` |
| 训练占比（%） / 验证占比（%） | `60` / `20` |

8. 点击“策略工作台”，按Ctrl+Home回到页面顶部。把下面两段AI输入准备好，录制时可粘贴。只复制输入文本，别把台本其他部分粘进去。
9. 用相同账号彩排一次完整流程。AI输出不固定，须确认真实调用可用；固定案例结果应与下文一致。正式录制重载案例，重新执行步骤，不把彩排响应或历史截图称为本次在线结果。

## 二、正式录制：按镜头操作

### 镜头1｜00:00–00:15：产品与流程

**操作**：页面顶部停留3秒，鼠标依次指向“智策工坊”、中间策略画布、右侧“AI 策略助手”。不要点删除积木。

**旁白**：

> 智策工坊是一款面向量化初学者的可视化研究软件。用户描述策略，AI生成积木候选，再经过规则核对、真实数据回测和样本外验证，形成可追溯的研究记录。

### 镜头2｜00:15–00:50：真实AI生成可见积木

**点击与输入**：

1. 在右侧“AI 策略助手”的需求输入框点击，按Ctrl+A，粘贴：

```text
收盘价 MA5 严格大于 MA20 时持仓比例为1，否则为0。必须是持续高于，不是上穿事件。MA窗口5和20、持仓比例1和0均为我指定的研究参数，不是最优参数。
```

2. 点击“生成策略候选”。拍到按钮变为“正在调用真实模型…”及真实返回。
3. 成功时应出现“候选策略已生成 · 尚未应用”，下面有实际模型、用量和条件说明。鼠标指向这些信息，停留2秒。
4. 核对说明确为MA5持续高于MA20、比例1/0，且“应用到画布”可点击，再点击它。
5. 点击中间画布下方“查看策略结构 JSON”，拍到 `ma`、`gt` 与持仓字段，停留2秒，然后再次点击收起。节点名称由模型生成，不要强求与人工案例相同。

**旁白**：

> 这里实际调用已配置的模型，把自然语言转为可编辑的策略积木。模型输出先通过结构校验，再由用户核对条件和参数。持续高于对应gt，上穿只表示交叉发生的当天，两者不能混用。

**通过条件**：候选真实返回，条件明确且按钮可用。若返回错误、拒绝或应用阻断，停下排查或重录；不要伪造成功画面，也不要点击恢复人工示例后称为AI生成。

### 镜头3｜00:50–01:05：载入固定真实数据案例

**操作**：

1. 按Ctrl+Home，点击顶部“载入真实案例”。这会替换刚才的AI候选，改为固定的人工案例。
2. 鼠标指向中间两张MA积木，以及右侧“组合股票集合”中的AAPL、IBM、MSFT。
3. 指向日期2012-01-03至2012-12-31。保留一键配置，不重新填写单股上限。

**旁白**：

> 为方便复现，下面切换到预先定义的人工案例，使用三只美股的真实历史日线。后续数字属于这个固定案例。三只股票逐日按条件筛选，共享一份资金账户。

### 镜头4｜01:05–01:35：主动制造一个窗口差异，演示审计与修复

**操作**：

1. 在中间画布找到右上角节点ID为 `fast` 的“移动平均线 MA”卡片。
2. 点击卡片的“窗口/历史滞后（记录数）”，Ctrl+A，把 `5` 改成 `10`，点击卡片外空白处。
3. 点击顶部导航“AI研究与审计”。预先填好的意图和契约仍应是5/20、持续高于、100%/0%。若为空，按录前表格补齐，不要带空契约点修复。
4. 点击“审计当前策略”。拍到“存在差异”，鼠标指向MA窗口的期望5/实际10及对应积木，停留2秒。
5. 点击“预览双MA修复”。拍到差异预览和“已核对明确项”。
6. 点击新出现的“确认应用修复”。点击导航“策略工作台”，拍到 `fast` 的窗口恢复为 `5`。

**旁白**：

> 我现在主动把五日窗口改成十日，演示系统如何发现需求和积木的差异。明确项审计定位到具体节点，先预览修复，再由用户确认。这个环节是确定性程序核对，不是大模型对任意策略正确性的证明。

**说明**：这是人工构造的错误案例，不得称为“刚才AI实际生成错误”。修复应用后旧回测及旧检查失效，下一镜头必须重新检查。

### 镜头5｜01:35–02:00：股票池检查与真实组合回测

**操作**：

1. 在右侧“回测配置”点击“检查股票池数据”。等待检查完成。
2. 拍到 `PASS`、请求3股、通过3股、共同日历250条。
3. 如果“运行真实回测”仍灰色，点击中间画布右上“校验策略”，等通过后再点击“运行真实回测”。
4. 等待运行完成，点击顶部导航“回测结果”。鼠标先指收益指标，再指净值曲线，停留3秒。

**旁白**：

> 回测前逐股检查价格质量、指标预热和日期覆盖，不会悄悄删除失败股票。这个案例共有二百五十个共同日期。策略累计收益约百分之一点五，低于同池等权买入持有的百分之十点五六，软件如实保留不理想的结果。

**固定案例复现值**：

| 指标 | 应出现的实际值（前端可有显示舍入） |
|---|---|
| 策略累计收益率 | `1.50%` |
| 股票池等权买入持有收益率 | `10.56%` |
| 最大回撤 | `-13.99%` |
| 策略夏普 / 买入持有夏普 | `0.201` / `0.668` |
| 逐股成交记录数 | `422` |

数字不同就先检查配置与画布，不改写旁白来掩盖差异。数值不是获利保证，也不是AI候选执行的结果。

### 镜头6｜02:00–02:20：术语帮助与来源

**操作**：

1. 点击“策略夏普比率”旁的 `?`。
2. 在解释弹窗稍向下滚动，拍到判断方向、经验参考与限制。
3. 点击弹窗右上“关闭解释”。
4. 点击净值图下方“数据来源与本次研究假设”，拍到来源、哈希和成本/滞后假设；拍清楚后再次收起。

**旁白**：

> 专业术语旁的帮助不仅解释定义，也说明如何阅读结果。正夏普在相同口径下通常越高越好，但经验参考不能替代样本外检验。报告同时保留数据来源和执行假设，让结果可以复核。

### 镜头7｜02:20–02:40：具体股票为何买入

**操作**：

1. 从回测结果稍向下滚动，越过账目表，找到“组合执行明细”。
2. 在“查看共同交易记录日”选择 `2012-02-01 · 3笔交易`。若已默认选中该日期，无需再次选择。
3. 鼠标依次指向信号来源 `2012-01-31`、本次选股AAPL/IBM/MSFT、下方交易表的买入方向和费用。

**旁白**：

> 二月一日的三笔买入使用前一条记录的信号，而非当天收盘信号当天成交。这里可看到具体入选股票、持仓、现金和费用，避免只给一条无法解释的收益曲线。

### 镜头8｜02:40–03:05：因子类型、关键词与论文

**点击与输入**：

1. 点击顶部导航“因子实验室”，向下滚到“02 核对公式与论文参考”。
2. 在“因子表达式”输入框核对或输入：

```text
close / MA(close, 20) - 1
```

3. 点击“预检、类型与论文参考”。
4. 拍到“价格结构（趋势/反转方向待验证）”、关键词与下方参考卡片。只展示卡片，不点击链接打开外部网站。

**旁白**：

> 这个因子度量价格相对二十日均线的偏离。程序依据表达式结构解释类型，并提供关键词与已核验论文参考。结构分类不能证明经济机制；这里的论文研究过拟合和选择偏差，是检验方法参考，不证明该因子有效。

**注意**：主线使用固定的人工因子，不称为AI本次挖掘出的公式。论文参考来自有限核验库，不称自动搜索所有论文。

### 镜头9｜03:05–03:20：先训练与验证，暂不看测试

**操作**：

1. 滚到“03 确认协议并评价因子”，拍到录前表格的协议数值。
2. 勾选“确认上述公式、集合、区间与分区协议，只评价训练/验证”。
3. 点击“运行因子训练/验证”。
4. 拍到“训练/验证已完成，最终测试未查看”和训练/验证两个分区。

**旁白**：

> 协议在运行前明确：预测跨度五条记录，按日期分为百分之六十训练、百分之二十验证和剩余测试。先只查看训练与验证，避免一边看测试、一边反复调整公式。

**复现值**：训练Rank IC约 `0.0794`，验证约 `0.1222`；训练378个配对、126个日期，验证135个配对、45个日期。最终测试此时不应显示得分。

### 镜头10｜03:20–03:55：AI依据真实因子证据解读

**操作**：

1. 点击顶部导航“AI研究与审计”，滚到“回测证据与AI解释”。
2. 勾选“确认向已配置AI发送选定摘要”。只勾同意框，不点击“AI解释选定证据”。
3. 点击顶部导航“因子实验室”，滚回刚才的训练/验证结果下方。
4. 点击“AI解读训练/验证证据”。等待真实返回。
5. 拍到“实际AI解释”、实际模型、带证据编号的说明及实际用量。解读内容由真实返回决定，不要求模型照台本说话。

**旁白**：

> AI的另一项作用是辅助理解实验结果。它接收用户确认的公式、训练验证指标和风险摘要，按证据编号组织解释，不发送整个行情包，也不提前发送最终测试结果。数值由本地内核计算，AI解释仍需复核。

**通过条件**：页面出现真实解释和引用编号。若接口失败，保留失败原因并重录这一段；不能把历史响应粘进画面称为本次调用。

### 镜头11｜03:55–04:15：冻结测试与风险边界

**操作**：

1. 在因子结果下方勾选“冻结当前已验证候选并查看测试；查看后再优化将污染测试独立性”。
2. 点击“冻结并评估最终测试”。不要改公式、日期或参数。
3. 向上少量滚动，拍到“最终测试已执行”和最终测试Rank IC约 `-0.0667`。
4. 向下滚到“风险审查”，拍到“样本独立性：证据不足”“参数敏感性：未执行”“PBO / DSR：未执行”。

**旁白**：

> 冻结后的测试段秩相关转为负值，说明训练验证的表现没有在本案例测试段延续。方向变化是风险线索，不能单独认定过拟合。系统明确列出未执行和证据不足项，不让AI编造过拟合概率。

**注意**：录前彩排、重复冻结或平台外实验均会影响独立性。视频展示的是冻结机制，不把这个已经反复演示的历史案例称为全新的独立发现。

### 镜头12｜04:15–04:40：保存、导出与结尾

**操作**：

1. 点击顶部导航“回测结果”。点击结果区右上“报告 JSON”。
2. 再点击“账目 CSV”和“净值图 PNG”。若浏览器出现允许连续下载提示，先处理；该提示可在彩排时允许，不要录到带个人路径的下载面板。
3. 按Ctrl+Home，点击顶部“保存策略”。这是策略工作台JSON，不是因子实验报告。
4. 页面停在名称和积木画布，保留3秒结束。无需展示文件资源管理器。

**旁白**：

> 最后可导出策略、真实回测报告、账目与净值图，保留可复现证据。智策工坊把AI候选、可视化规则、明确项审计和因子验证连成一个研究流程，帮助初学者理解结果与风险。当前是研究工具，不承诺投资收益。

## 三、可选替换镜头：突出AI因子候选（不与主线同时塞满）

如果你更想突出“AI辅助挖掘因子”，可用以下25秒替换镜头6的术语帮助，并压缩5秒其他停留；录前彩排调用时间。不要增加到5分钟以上。

1. 点击“因子实验室”，在“01 提出因子研究假设”的“因子研究问题”输入：

```text
请只提出一个可供研究的因子候选：收盘价相对20日简单移动平均线的偏离，表达式为 close / MA(close, 20) - 1。解释研究假说与可能失效情景。20是我指定的演示窗口，不是最优参数；不要声称因子已经有效，不要提供投资建议。
```

2. 勾选“确认调用真实AI生成一个候选，可能产生API费用”，点击“AI提出因子候选”。
3. 拍到真实返回的公式、待验证假说、失效条件和实际模型。只有候选可用、核对后才点“确认使用候选公式”。
4. 若返回表达式与固定因子完全相同，可沿用主线后续协议与数字；如不同，不能套用上文数字。为了走固定复现主线，可在镜头8明确说“下面换回预先指定的人工因子”，手动输入固定公式；或使用AI公式重新执行全流程，并按实际结果重新配旁白。

**该段旁白**：

> AI根据明确的研究问题提出因子候选、假说与失效情景。候选并不等于发现有效因子，用户核对公式后，仍须通过真实数据分区评价和样本外检验。

这是用户限定形式的AI候选演示，不宣传为AI自主发现新因子。

## 四、常见卡点与处理

| 情况 | 具体处理 |
|---|---|
