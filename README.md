# 智策工坊（FinBlocks）

AI可视化策略与因子研究工作台，包含沪深300股票池、技术指标、组合回测、因子风险解释和本机账号。

**下载使用：Code → Download ZIP → 解压 → Windows双击 `start.cmd`。**需要已有Python 3.10或更新版本，不需要安装项目依赖。

完整步骤、金融数据导入与可选AI配置见 [组员使用说明](TEAM_README.md)。macOS/Linux执行 `python3 start_finblocks.py`。

**网页版部署配置已准备**，域名服务、组员邀请码、持久化目录与管理员分片上传见 [线上部署说明](ONLINE_README.md)。目前未在外部平台创建服务，不提供虚构在线地址。

**无需原始大数据包即可演示**：点击“载入真实案例”→“检查股票池数据”→“运行真实回测”。包内含Bokeh官方样例的2012年AAPL/IBM/MSFT日线750条，并保留来源及BSD-3-Clause许可；它不代表沪深300或最新行情。

点击“导入行情CSV”可接入自有OHLCV，详见[CSV接入说明](docs/csv_data_import.md)。原始完整行情、API密钥、个人账号和历史导出不在共享包。AI使用成员自己的服务商账号，登录时或顶部AI设置可配置。GitHub仓库用于分发源码，软件后端须在成员电脑运行。
