# FinBlocks

AI可视化策略与因子研究工作台，包含沪深300股票池、技术指标、组合回测、因子风险解释和本机账号。

**下载使用：Code → Download ZIP → 解压 → Windows双击 `start.cmd`。**需要已有Python 3.10或更新版本，不需要安装项目依赖。

完整步骤、金融数据导入与可选AI配置见 [组员使用说明](TEAM_README.md)。macOS/Linux执行 `python3 start_finblocks.py`。

没有金融数据时可浏览和编辑，回测会明确阻断；真实数据、API密钥、个人账号和历史导出不在本仓库。在线AI使用成员自己的DeepSeek账号。GitHub仓库用于分发源码，软件后端须在成员电脑运行。
